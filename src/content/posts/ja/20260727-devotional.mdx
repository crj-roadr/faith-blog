# ディボーション使徒言行録17章：パウロのアレオパゴスでの信仰の擁護

今日のディボーションは使徒言行録17章にあり、そこで起きたことは以下の通りです。

**概要:** この章では、パウロ、シラス、そして彼らの仲間たちは、エルサレムの使徒たちと教会から遣わされ、イエス・キリストの命令（すなわち、福音をすべての国々に広めること）を実践し続けていました。彼らが通る場所ごと、彼らは次の順序で福音を広めていました。ユダヤ人に対してはシナゴーグで、その後、敬虔な異邦人に対して。まず、彼らはテサロニケで福音を宣べ伝え、そこで多くの人々（ユダヤ人と異邦人）が回心しました。しかし、妬むユダヤ人たちは騒動を引き起こし、権力者たちに訴えて彼らを追い出しました。次に、彼らはベレアに逃れ、そこにはテサロニケよりも高貴で熱心な読者が多くいました。そこで彼らはキリストの福音を説明し、議論する上でより体系的になる必要がありました。しかし、多くの人々が回心したにもかかわらず、テサロニケのユダヤ人たちは彼らの働きを阻止するために、彼らが福音を宣べ伝えていることを知るとやってきました。最後に、彼らはアテネに逃れ、そこでパウロはアテネの人々の偶像崇拝に憤慨しました。さらに、パウロが良き知らせを宣べ伝えていると、民衆は彼が知らない神々について話すことを嘲笑しました。そのため、彼らはパウロをアレオパゴスに連れて行き、彼が宣べている教えがどのようなものであるかを正当化させました。パウロは民衆の前で彼の信仰と教えを守るために演説し、彼らが「知られていない神」と呼んでいる神が、自分が語り、守っている神であることを説明しました。最終的に、多くの人々がイエス・キリストを信じるようになりました。

## 観察（気づき）

以下は私の観察です。

1. 敵対者による勇敢なキリスト者への迫害は絶え間ない。イエス・キリストは天に昇る前に、私たちに福音を地の果てまで広めるように命じられました（マルコ 16:15）。しかし、彼はまた、私たちがキリストのゆえに迫害され、それゆえに幸いであると警告されました（マタイ 5:10–12）。さらに、彼はこの世で私たちは苦難に遭うが、彼が世に勝利したので、彼にあって平安を見いだすであろうと断言されました（ヨハネ 16:33）。そしてこの章で、パウロ、シラス、そして彼らの仲間たちは、イエスが約束された通りの様々な苦難を経験しました。しかし、彼らは決して落胆しませんでした。それどころか、彼らはさらに大胆になり、彼らが宣教している人々の信仰に対して、より良い説明と議論を続けました。これはクリスチャンとして私たちが adopt すべき態度の模範です。なぜなら、今日、考え方の不寛容と意見の相違によるキャンセルカルチャーのために、福音を分かち合い、イエス・キリストの真実を擁護することはますます難しくなっているからです。ですから、私たちはあらゆる困難に立ち向かう準備をする必要があります。なぜなら、主は私たちと共におられるからです（詩編 23:4）。
2. 私たちは常に自分たちの信仰と信念を守る準備ができていなければならない。この章で、パウロと仲間たちは、テサロニケ、ベレア、アテネで、自分たちの信念を正当化する議論を持っている学識ある人々に遭遇しました。したがって、彼らは人類の主であり救い主であるイエス・キリストへの信仰を正当化するために、良い議論と証拠を提示する必要がありました。もし彼らがイエス・キリストへの信仰をうまく守れなかったなら、キリスト教への改宗の過程で多くの人々を助けることができなかったでしょう。そのため、シモン・ペトロは次のように私たちに語りました。「心を清めて主キリストを呼び求めなさい。あなたがたが持っている望みについての justification を尋ねる者に、いつでも meekness と respect を持って答えなさい」（1 ペトロ 3:15）。それゆえ、私たちは聖書を学び続け、神からの知恵と理解を求めなければなりません。そうすれば、私たちは人類の主であり救い主であるイエス・キリストへの信仰と信念を適切に擁護することができます。そうすることで、迷っている人々は疑問を解消し、真実への渇きを癒すことができるでしょう。
